Тип      Размер     Пример объявления
---------------------------------------------
byte     1 байт     byte b = 10;
short    2 байта    short s = 500;
int      4 байта    int i = 150000;
long     8 байт     long l = 4000L;
float    4 байта    float f = 3.14f;
double   8 байт     double d = 2.71828;
char     2 байта    char c = 'A';
boolean  1 бит*     boolean isReady = true;


Ключевые особенности примитивов:

1. Память и производительность: Примитивы хранятся на стеке (Stack), в то время как объекты создаются в куче (Heap). Работа со стеком происходит значительно быстрее.
2. Не могут быть null: Переменная примитивного типа всегда хранит конкретное значение. Ей нельзя присвоить null.
3. Отсутствие методов: У примитивов нет встроенных методов (вы не можете вызвать, например, int.toString()).
4. Классы-обертки (Wrapper Classes): Для каждого примитива существует свой ссылочный объект-двойник (Integer для int, Double для double и т.д.). Они нужны, чтобы работать с примитивами внутри коллекций (например, в ArrayList<Integer>), так как коллекции не умеют хранить примитивы напрямую. Процесс автоматического преобразования между ними называется автоупаковкой и автораспаковкой (Autoboxing/Unboxing).
5. Важно для денежных расчетов: Типы float и double используют стандарт IEEE 754 (числа с плавающей точкой) и могут допускать небольшие погрешности из-за округления двоичных дробей (например, 0.1 + 0.2 в Java даст 0.30000000000000004). Для финансовых расчетов вместо них используют ссылочный тип BigDecimal.
